# Rank-15 dimension types

[published-rank15-perfect.txt](published-rank15-perfect.txt) is the input to the [rank-15 check](../code/verify_rank15_published.py). Its 2341 lines give the published list of remaining perfect dimension types in rank 15, one sorted list per line. The program verifies the checksum and the number of distinct lists before computing the distribution of prime divisors.
