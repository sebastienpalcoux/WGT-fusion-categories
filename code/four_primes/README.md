# Four-prime residue and trace calculations

Run these commands in this directory with Python 3.10 or later. They use the standard library. Each input fixes a repeated-prime position or a height from the stated theorem. The other primes range over the entire proven window. The periodic projections also allow an unbounded opposite height.

## Two fixed higher exponents

```sh
python dyadic_total_height.py
for P in 3 5 7 11 13 17 19; do python new_odd.py "$P"; done
```

The first command reproduces the seven rows in the proof of Theorem 9.15, “Total height at two higher primes.” In root-height order (2,2), (2,3), (3,2), (2,4), (4,2), the signed vacuum counts are 12, 14, 92, 18 and 365. It prints each surviving negative common term, the residual budget for the dyadic axis, all attainable nonempty trace residues and the excluded residue. Two common exponent pairs share one printed row. The command exits unsuccessfully if a common term survives at both endpoints.

The second command reproduces the seven odd least-prime columns of the octic window using one test. It charges a dual pair on each of the two mandatory axes and asks whether one admissible common degree can give the required negative sign within both remaining norm budgets. No summation over complete Gram solutions is needed.

| Least prime | 3 | 5 | 7 | 11 | 13 | 17 | 19 |
|---|---:|---:|---:|---:|---:|---:|---:|
| Vacuum classes | 14 | 59 | 181 | 1338 | 2706 | 8065 | 12977 |
| Positive residual axis budgets | 0 | 3 | 0 | 1 | 0 | 1 | 1 |
| Allow a negative common term | 0 | 0 | 0 | 0 | 0 | 0 | 0 |

For the full Gram-sum and trace check at fixed dyadic and odd higher positions, use `python check_four.py 2 h k` with root heights h,k at least two.

## Periodic higher exponents

```sh
python unbounded_four.py
python prime_projection.py 3 4
python independent_projection.py 3 4
python odd_periodic.py 3 3 4
python odd_trace.py 3 3 4
```

At dyadic root height two there are 279 classes, then 53 after the axis minima and two after the Gram test. The last trace excludes both classes. At dyadic heights three and four the two independent projection programs give 9 and 39 possible opposite primes, with respective maxima 37 and 283. These two rows are necessary conditions.

The last command includes the initial ternary projection. At ternary height three the two remaining rows both have opposite prime 11 and already fail the trace modulo its square. At height four the eleven initial rows have opposite prime in 5, 7, 11, 19, 29. Reduction of the residual trace modulo its second, third and fourth powers leaves five, one and zero rows respectively.
