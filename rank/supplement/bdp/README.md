These are the audited Burciu–Dong–Palcoux scripts for the finite word and four-prime projections quoted in the family catalogue. Their source is commit f2ef6eedb58ade6adcdb5ed9caeba1836b4ba8ce of https://github.com/sebastienpalcoux/WGT-fusion-categories. The ordinary rank search reads no BDP list of types. The saved ranks have a separate verification with the elementary BDP divisor cones, small codegrees and traces in the main paper.

The two independent projections for the sets S3 and S4 are run from four_primes with python3 prime_projection.py 3 4 and python3 independent_projection.py 3 4. See the README in that directory for the remaining finite height and residue tests. The statements and hypotheses of the inherited BDP family theorems remain mathematical inputs to the new work.
